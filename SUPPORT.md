# Support

If you run into a problem, please open an issue:

https://github.com/whyisee/z-epub-reader/issues

Useful details to include:

- Cursor or VS Code version
- Operating system
- Extension version
- Whether the EPUB is EPUB 2 or EPUB 3, if known
- What happened, what you expected, and whether the problem repeats with another EPUB

Please do not upload copyrighted EPUB files unless you have the right to share them. A small reproducible sample or screenshots are usually enough.
